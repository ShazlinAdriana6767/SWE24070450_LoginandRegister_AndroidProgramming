# Login and Register

An Android app that lets users create an account and log in using Firebase Authentication.

## Features
- Sign up with email and password (with password confirmation and a 6-character minimum)
- Log in with email and password
- Error messages shown with Toasts

## Built with
- Kotlin
- Android Studio
- Firebase Authentication

## Setup
1. Clone the repository.
2. Create a Firebase project and register an Android app with the package name `com.week14.loginandregister`.
3. Download `google-services.json` and place it in the `app/` folder.
4. In Firebase, enable **Authentication > Sign-in method > Email/Password**.
5. Sync Gradle and run the app.
